Why the Marker Uses Entity Encoding

The validation check performs a direct literal string scan. If the canary word were written plainly across descriptive paragraphs or documentation code blocks, deleting the genuine health marker would still leave matches behind — preventing the failure circuit breaker from ever triggering.

&info; Entity Encoding Safeguard
Every reference throughout this document — except for the single health comment at the top — is rendered via the HTML entity SITE&#45;OK. Browsers render a standard hyphen, while grep sees distinct byte sequences.
